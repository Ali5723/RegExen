# RegExen

**RegExen** is a free and open-source tool that helps developers write, test, visualize, and understand regular expressions (Regex).

### 🚀 [Try RegExen Live](https://regexen.vercel.app/)

**Live Website:** https://regexen.vercel.app/

Regular expressions are powerful, but they can often be difficult to write, understand, and debug. RegExen aims to simplify this process by providing an interactive environment where developers can experiment with patterns, instantly inspect matching results, and eventually explore how regular expressions work behind the scenes.

The project is currently under active development, with more features and improvements planned.

---

## ✨ Features

### 🧪 Regex Tester

The Regex Tester is the first functional tool available in RegExen.

- **Live Regex Testing:** Write a regular expression and test it against custom text, with results updating instantly.
- **Regex Flags:** Enable or disable supported flags to control matching behavior.
- **Pattern Validation:** Instantly check whether a regular expression is valid.
- **Match Detection:** Find and display matches within the provided text.
- **Match Results:** View matching results in an organized, scrollable list.
- **Input Statistics:** Track the number of lines and characters in the test input.
- **Copy Pattern:** Quickly copy your regular expression to the clipboard.

### 🎨 Interface & User Experience

RegExen is designed to provide a clean and comfortable development experience.

- **Light & Dark Themes:** Two carefully designed color schemes with consistent styling and contrast.
- **Responsive Design:** Optimized layouts for desktop and mobile devices.
- **Reusable Components:** A consistent UI built with reusable components.
- **Accessibility:** Improved keyboard and screen-reader support through accessible controls and ARIA attributes.
- **Developer-Friendly Interface:** A simple, organized workspace focused on usability.

## 🔮 Upcoming Features

RegExen is more than just a regex tester. The long-term goal is to build a complete environment for exploring and understanding regular expressions.

### 🔍 Regex Explainer

Break down regular expressions into understandable parts, including character classes, quantifiers, groups, assertions, and other regex constructs.

### 🎬 Execution Visualizer

Visualize how supported regular expressions are evaluated step by step, making matching behavior and backtracking easier to understand.

### 🧩 Advanced Match Inspector

Highlight matches directly inside the input text and inspect capturing groups, named groups, and match positions.

### 🔄 Replace & Extract

Experiment with regex-based text replacement, preview transformations, and extract structured data from matching results.

### 🧪 Test Cases

Create multiple test cases for a single expression, define expected results, and verify that patterns continue working as intended.

### ⚡ Performance Analysis

Explore regex performance, compare execution times, and identify patterns that may cause inefficient matching behavior.

### 📚 Interactive Learning

Learn regular expressions through interactive examples, explanations, and practical challenges.

_These features are planned and are not all implemented yet._

## 🚀 Getting Started

You can try RegExen immediately using the [live website](https://regexen.vercel.app/), or run it locally for development.

### Prerequisites

Make sure you have the following installed:

- Node.js
- pnpm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Ali5723/RegExen.git
cd RegExen
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Start the Development Server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server supports hot reloading, so your changes will appear automatically while developing.

---

## 📦 Build for Production

Build the application:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
